====================================================
dsh-message-rail 安装说明（版本 0.2.0）
====================================================

【这是什么】
dsh 桌面端插件：会话右侧的消息导航条（ChatGPT 式）。
- 右侧一列竖条，每条 = 一条你发送的消息
- 悬停：当前条变长变亮、上下相邻条波纹起伏、左上方浮出消息开头文字
- 点击：平滑滚动跳转到对应消息并闪烁定位
- 条数装不下时：鼠标贴近导航条上/下边缘自动滚动，也可直接用滚轮

【前提】
对方必须已安装 dsh 桌面端（本插件依赖 dsh 的会话界面和主题样式，不是独立软件）。


----------------------------------------------------
安装步骤
----------------------------------------------------

第 1 步：解压
  解压 dsh-message-rail.zip，得到 message-rail 文件夹。
  把它放到一个固定位置，建议放到 dsh 配置目录下，例如：
    C:\Users\你的用户名\.dsh\profiles\desktop\message-rail

第 2 步：注册插件
  用记事本或编辑器打开这个文件：
    C:\Users\你的用户名\.dsh\profiles\desktop\package.json
  做两处修改（都是 JSON，注意逗号别出错）：

  (1) 在 "dependencies" 里加一行。
      路径改成你第 1 步的实际路径，并且用正斜杠 / ：
        "dsh-message-rail": "link:C:/Users/你的用户名/.dsh/profiles/desktop/message-rail"

  (2) 在 "dsh" -> "profile" -> "bundles" 数组里加一项：
        "dsh-message-rail"

  完整示例（路径以你的实际为准）：
    {
      "dependencies": {
        "dsh-message-rail": "link:C:/Users/你的用户名/.dsh/profiles/desktop/message-rail"
      },
      "dsh": {
        "profile": {
          "bundles": [
            "@deepseek-ai/dsh-base",
            "@deepseek-ai/dsh-web-app",
            "dsh-message-rail"
          ]
        }
      }
    }

第 3 步：安装依赖
  在 C:\Users\你的用户名\.dsh\profiles\desktop 目录下运行：
    pnpm install
  （如果提示没有 pnpm，先运行：npm install -g pnpm）

第 4 步：重启 dsh 桌面端
  重启后打开任意对话，右侧就会出现导航条。


----------------------------------------------------
验证是否成功
----------------------------------------------------
- 对话里有超过 1 条你的发言，右侧就会出现一列竖条。
- 打开历史较长的对话时，它会自动把更早的消息加载补全
  （这是插件的正常行为，目的是让导航条覆盖完整对话，稍等几秒即可）。


----------------------------------------------------
可选调整（改样式）
----------------------------------------------------
用编辑器打开 message-rail\lib\client.js，改顶部「参数」区的数值：
  W_DEFAULT / W_ADJ2 / W_ADJ1 / W_ACTIVE   四态宽度（默认/临2/临1/被选，依次变长）
  BAR_H          条高（默认 4）
  GAP            条间距（默认 6）
  MAX_RAIL_H     导航条最大高度占视口比例（默认 0.30，越小越容易滚动）
  EDGE_ZONE      边缘自动滚动触发区（默认 24，贴边多少 px 内触发）
  EDGE_SPEED     边缘滚动速度（默认 3，越大滚越快）
  AUTO_LOAD_ALL  是否自动补全历史（默认 true；改 false 则只显示已加载的消息）
改完保存，重启 dsh 生效。


----------------------------------------------------
卸载
----------------------------------------------------
1. 打开 package.json，删掉你加的两处（dependencies 和 bundles 里的 dsh-message-rail）。
2. 在该目录再跑一次：pnpm install
3. 删除 message-rail 文件夹，重启 dsh。
